## ⚡ The VOUT Software Ecosystem

#### 📱 [VOUT](https://github.com/AgustinMilesi/expenses) — Mobile Expense & Subscription Tracker
Personal finance, recurring commitments, and micro-spending mobile tracker built with React Native and NativeWind in a Cyber Lime & Deep Obsidian palette.
- ⚡ **Highlights:** Disposable income gauge ("Safe to Spend"), instant numeric keypad for micro-expenses, 3-tier accelerometer shake-to-update gesture, and offline-first storage.
- 🛠️ **Stack:** React Native, Expo SDK 58, TypeScript, NativeWind v4, AsyncStorage.
- 📲 **[Download APK v1.0.3.2](https://github.com/AgustinMilesi/expenses/releases/latest/download/VOUT.apk)** • 🌐 **[Live Web App](https://vout-web.vercel.app)** • [Web Hub](https://github.com/AgustinMilesi/expenses-web) • [Source Code](https://github.com/AgustinMilesi/expenses)

<br/>

#### 💳 [VOUT Retail](https://github.com/AgustinMilesi/retail) — Cloud Point of Sale & Store Engine
Cloud point of sale, store management, and ledger auditing system built for high-throughput retail stores.
- ⚡ **Highlights:** Barcode scanner checkout, blind cash drawer shifts with discrepancy audits, atomic inventory transactions, and thermal receipt printing.
- 🛠️ **Stack:** Next.js 16, React 19, TypeScript, Neon Serverless Postgres, Prisma ORM, Tailwind CSS v4.
- 🚀 **[Live Demo](https://milesi-erp.vercel.app)** • [1-Click Guest Access](https://milesi-erp.vercel.app/demo) • [Source Code](https://github.com/AgustinMilesi/retail)

<br/>

#### 📥 [VOUT Inbox](https://github.com/AgustinMilesi/inbox) — Multi-Tenant Customer Feedback Platform
Multi-tenant SaaS platform to collect customer inquiries through embeddable web forms and triage them in a unified real-time inbox.
- ⚡ **Highlights:** Strict organization data isolation, embeddable forms via `<iframe>` & API, signed HMAC-SHA256 webhooks, and REST API v1.
- 🛠️ **Stack:** Next.js 16, React 19, TypeScript, Neon Postgres, Prisma ORM, Resend API.
- 🚀 **[Live Demo](https://saas-am.vercel.app)** • [1-Click Guest Access](https://saas-am.vercel.app/demo) • [Source Code](https://github.com/AgustinMilesi/inbox)

<br/>

#### 🚢 [VOUT Cargo](https://github.com/AgustinMilesi/cargo) — Freight Logistics & Customs OS
International freight forwarding, customs clearance, and real-time cargo tracking platform for ocean and air shipments.
- ⚡ **Highlights:** Container and B/L tracking, customs clearance channels (Green/Orange/Red), multimodal rate calculator, and protected client self-service portal.
- 🛠️ **Stack:** Next.js 16, React 19, TypeScript, Neon Postgres, Prisma ORM, Tailwind CSS v4.
- 🚀 **[Live Demo](https://cargo-am.vercel.app)** • [1-Click Guest Access](https://cargo-am.vercel.app/demo) • [Source Code](https://github.com/AgustinMilesi/cargo)

<br/>

#### 📬 [VOUT Connect](https://github.com/AgustinMilesi/contact) — High-Conversion Contact Portal
Minimalist contact portal and lead capture gateway with dual-layer validation and silent honeypot anti-spam protection.
- ⚡ **Highlights:** Shared client/server Zod validation, invisible bot trap, and instant transactional email dispatch via Resend.
- 🛠️ **Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS v4, Zod, Neon Postgres, Resend API.
- 🚀 **[Live Demo](https://agustinmilesi-contact.vercel.app)** • [Source Code](https://github.com/AgustinMilesi/contact)
