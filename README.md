### 🚀 Ecosistema de Proyectos

#### 💳 Retail Engine & POS
Sistema de punto de venta y gestión comercial en tiempo real diseñado para alta velocidad operativa.
- ⚡ **Funcionalidades:** Lectura de códigos de barra, arqueo ciego de caja con cálculo de diferencias, deducción atómica de inventario (ACID), tickets térmicos y modo oscuro.
- 🛠️ **Stack:** Next.js 16, React 19, TypeScript, Neon Serverless Postgres, Prisma ORM, Tailwind CSS.

[![Demo en Vivo](https://img.shields.io/badge/Demo_en_Vivo-6366F1?style=for-the-badge&logo=vercel&logoColor=white)](https://milesi-erp.vercel.app)

#### 📥 Customer Inbox & Forms Platform
Plataforma multi-tenant para centralizar consultas de clientes mediante formularios web embebibles.
- ⚡ **Funcionalidades:** Aislamiento estricto por workspace, formularios embebibles vía `<iframe>` y API headless, webhooks firmados con HMAC-SHA256 y API REST v1.
- 🛠️ **Stack:** Next.js 16, React 19, TypeScript, Neon Postgres, Prisma, Webhooks HMAC, REST API.

[![Demo en Vivo](https://img.shields.io/badge/Demo_en_Vivo-6366F1?style=for-the-badge&logo=vercel&logoColor=white)](https://saas-am.vercel.app)

[![Entrar como Invitado](https://img.shields.io/badge/Entrar_como_Invitado-1--Click_Demo-10B981?style=for-the-badge&logo=auth0&logoColor=white)](https://saas-am.vercel.app/demo)

<br/>

#### 📬 Contact & Lead Portal
Portal de contacto y captación de clientes con protección activa anti-spam.
- ⚡ **Funcionalidades:** Validación dual cliente/servidor con Zod, trampa honeypot invisible anti-bots y despacho transaccional con Resend.
- 🛠️ **Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS, Zod, Neon Postgres, Resend API.

[![Demo en Vivo](https://img.shields.io/badge/Demo_en_Vivo-6366F1?style=for-the-badge&logo=vercel&logoColor=white)](https://agustinmilesi-contact.vercel.app)
[![Código](https://img.shields.io/badge/Código_Fuente-18182E?style=for-the-badge&logo=github&logoColor=white)](https://github.com/AgustinMilesi/contact)

<br/>

#### 🚢 OneCargo — Freight Logistics OS
Plataforma de gestión para freight forwarders y seguimiento de contenedores marítimos y aéreos.
- ⚡ **Funcionalidades:** Rastreo en vivo por contenedor o B/L, despacho de aduana, cotizaciones multimodales, portal de clientes, selector de tema/color y soporte para 4 idiomas.
- 🛠️ **Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS, Prisma ORM, Neon Postgres Cloud.
