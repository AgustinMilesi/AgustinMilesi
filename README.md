## 🏛️ Engineering Standards & Production Architecture

Every system in the **VOUT** ecosystem is built following enterprise software standards, avoiding generic boilerplate and amateur "vibecoding" shortcuts:

- 🛡️ **Zero-Trust Multi-Tenancy & Security**: Strict organization-scoped Prisma queries, signed HMAC-SHA256 webhook relays, memory-pruning rate limiters, and honeypot bot traps.
- ⚡ **SSR & Server-First Performance**: Built on Next.js App Router (RSC) and React 19. Instant first-contentful paint with zero empty client SPA shells.
- 📐 **Semantic Integrity & A11y (WCAG 2.2 AA)**: Strict single-`<h1>` document outline hierarchy, custom branded 404 error handlers, keyboard skip links, and ARIA landmarks across all suites.
- 🤖 **AI & Search Engine Readiness**: Full OpenGraph / Twitter Cards, Schema.org JSON-LD structured data (`SoftwareApplication`), dynamic `sitemap.xml`, permissive `robots.txt`, and machine-readable `/llms.txt` endpoints across every deployment.
- 🎨 **Cohesive Obsidian Design System**: Unified Obsidian Dark (`#0A0E14`) and Cyber-Lime (`#C6F827`) palette with custom glassmorphism, HUD telemetry panels, and theme switcher engines.

### Deep Dives

#### 📱 [VOUT](https://github.com/AgustinMilesi/expenses) — Mobile Expense & Micro-Spending Tracker
Personal finance and recurring commitment manager built with React Native and NativeWind.
- ⚡ **Key Features**: Instant numeric keypad for micro-expenses, real-time disposable income gauge ("Safe to Spend"), accelerometer shake gesture, and offline-first storage.
- 🛠️ **Stack**: React Native, Expo SDK 58, TypeScript, NativeWind v4, AsyncStorage, Next.js 16 Web Hub.
- 📲 **[Download Android APK](https://github.com/AgustinMilesi/expenses/releases/latest/download/VOUT.apk)** • 🌐 **[Live Web App](https://vout-web.vercel.app)** • [GitHub Repo](https://github.com/AgustinMilesi/expenses)

<br/>

#### 💳 [VOUT Retail](https://github.com/AgustinMilesi/retail) — Point of Sale & Store Engine
Enterprise POS and store management suite engineered for high-throughput retail operations.
- ⚡ **Key Features**: Real-time barcode scanner, blind cash drawer shift opening/closing with discrepancy audits, atomic inventory transactions, and thermal receipt printing format.
- 🛠️ **Stack**: Next.js 16, React 19, TypeScript, Neon Serverless Postgres, Prisma ORM, Tailwind CSS v4.
- 🚀 **[Live ERP Demo](https://milesi-erp.vercel.app)** • [1-Click Guest Session](https://milesi-erp.vercel.app/demo) • [GitHub Repo](https://github.com/AgustinMilesi/retail)

<br/>

#### 📥 [VOUT Inbox](https://github.com/AgustinMilesi/inbox) — Multi-Tenant Feedback & Form Platform
Multi-tenant customer inquiry system with embeddable web forms and event streaming.
- ⚡ **Key Features**: Strict organization data isolation at the ORM layer, embeddable contact widgets, HMAC-SHA256 signature verification on webhook dispatches, and public API keys.
- 🛠️ **Stack**: Next.js 16, React 19, TypeScript, Neon Postgres, Prisma ORM, Resend API.
- 🚀 **[Live SaaS Demo](https://saas-am.vercel.app)** • [1-Click Guest Session](https://saas-am.vercel.app/demo) • [GitHub Repo](https://github.com/AgustinMilesi/inbox)

<br/>

#### 🚢 [VOUT Cargo](https://github.com/AgustinMilesi/cargo) — Freight Logistics & Customs OS
Global logistics and freight management suite for international container tracking and customs dispatching.
- ⚡ **Key Features**: Multi-carrier container / B/L tracking with milestone progression, customs clearance channel management (Green / Orange / Red), multimodal rate estimation, and consignee self-service portal.
- 🛠️ **Stack**: Next.js 16, React 19, TypeScript, Neon Postgres, Prisma ORM, Tailwind CSS v4.
- 🚀 **[Live Logistics Demo](https://cargo-am.vercel.app)** • [1-Click Guest Session](https://cargo-am.vercel.app/demo) • [GitHub Repo](https://github.com/AgustinMilesi/cargo)

<br/>

#### 📬 [VOUT Connect](https://github.com/AgustinMilesi/contact) — High-Conversion Architectural Gateway
Central portfolio hub and inbound lead gateway.
- ⚡ **Key Features**: Dual-layer client/server Zod validation, invisible bot trap, in-memory rate limiting with memory-pruning protection, and direct transactional email dispatch.
- 🛠️ **Stack**: Next.js 16, React 19, TypeScript, Tailwind CSS v4, Zod, Neon Postgres, Resend API.
- 🚀 **[Live Gateway](https://agustinmilesi-contact.vercel.app)** • [GitHub Repo](https://github.com/AgustinMilesi/contact)
